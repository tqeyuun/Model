# 최종 테스트 사전 등록 (최종 테스트 실행 전에 고정)

## 고정 설정 (설정 변경 4/5 사용, 남은 1회 미사용 — 최종 테스트 전에는 더 쓰지 않음)
- 회당 매수액 1,000 고정 / 주요(SPY, QQQ) -5% / 비주요(XLE, XLF) -15% / 단계: 임계의 배수 도달 시마다 1회 매수, 전고점 갱신 시 초기화
- XLF: 전일까지 (DGS10-DGS2) >= 0 일 때만 매수 / 월 1,000 입금(자산당) / 체결 = 신호 다음 거래일 시가 / 비용 편도 0.075%
- 대기 현금: 전일 DGS2 금리 일할 이자 반영 / 평가는 수정종가 기준
- 시도 후 폐기·미채택: 비율 매수(50/100%), 주요 -3%, 회당 2,000, 하락 단계 비례 매수 (CONFIG_LOG.md 참고)

## 실행 방법
- `python3 src/final_test.py --confirm-final-test` — 사용자가 "최종 테스트 실행해줘"라고 명시했을 때만. 1회만 실행.
- 판정은 계획서 합격 기준 1~4 그대로 (정액적립 비교, 비용 반영 후). 기준을 사후에 완화하지 않는다.
- 최종 테스트 결과를 보고 설정을 바꾸지 않는다 (튜닝 금지).

## 사전 점검에서 알려진 점 (최종 테스트 결과를 보기 전의 예상)
- 합격 기준 2(총수익률 >= 정액)는 학습·검증 모두 미달이라 미달 가능성이 높다.
- 합격 기준 3(XLF 금리 조건)은 학습·검증에서 한 번도 작동하지 않아 효과 검증 불가였다. 최종 테스트에서도 동일하면 '동일'은 형식상 통과일 뿐 효과의 증거가 아니다.

## 미달 시 새 시도 규칙 (계획서)
- 최대 2번, 바꿀 수 있는 것은 **하락률 기준 또는 비주요 섹터 종목뿐**. 데이터·검증 틀·합격 기준 유지, 기준 완화 금지. 2번 모두 실패 시 정액적립으로 전환.
- 매수 금액 방식(예: 하락 비례 매수)은 새 시도 대상이 아니다.
- 열린 문제(사용자 결정 필요): 최종 테스트는 1회만 열 수 있으므로, 새 시도를 어떤 구간에서 판정할지 계획서에 명시가 없다.

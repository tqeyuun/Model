# 미장 ETF 적립 전략 2 — 모델 1·5 정리 (최종 테스트 미실행)

## 상태
- 구현: `src/model1.py`, `src/model5.py` (IEF 데이터는 `src/fetch_ief.py`). 학습·검증만 사용, `_sealed_test` 봉인 유지.
- 시험 조합은 사전 등록한 8개(1-A~D, 5-A~D)만 실행. 설정 변경·추가 조합 없음.

## 모델 1 (하락 가중 배분, 현금 0%) — 검증 2019~2022
| 조합 | 최종가치 (모델1 / 기준① / 기준②) | 최대낙폭 (모델1 / 기준①) | 문서 기준 |
|---|---|---|---|
| 1-A k=1 | 52,816 / 52,803 / 52,805 | -30.7% / -30.8% | 형식상 충족 |
| 1-B k=0.5 | 52,807 / 52,803 / 52,801 | -30.7% / -30.8% | 형식상 충족 |
| 1-C k=2 | 52,800 / 52,803 / 52,792 | -30.7% / -30.8% | 미달 |
| 1-D 섹터 포함 | 57,671 / 57,004 / 57,485 | -34.2% / -34.0% | 미달 (연도별 우위 50%) |

- SPY·QQQ는 같이 움직여 하락 점수가 비슷하므로 평균 비중이 50±0.3%에 머문다. 균등 적립과 수익률이 사실상 같다.
- 1-A·1-B의 "충족"은 최종가치 10~15달러 차이로, 문서의 "여유 있게 넘은 경우만 인정"에 해당하지 않는다. 결론: 우위 없음.

## 모델 5 (주식·채권 + 입금 리밸런싱) — 검증 2019~2022, 기준 100% 주식 정액적립
| 조합 | 최종가치 비율 | 낙폭 감소 (≥30%) | 샤프 (기준 0.68) | 판정 |
|---|---|---|---|---|
| 5-A 80:20 | 96% | 12% | 0.67 | 미달 |
| 5-B 90:10 | 98% | 7% | 0.68 | 미달 |
| 5-C 80:20 + 강화 | 96% | 10% | 0.66 | 미달 |
| 5-D 90:10 + 강화 | 99% | 6% | 0.67 | 미달 |

- 2022년 주식·채권 동반 하락으로 채권이 낙폭을 거의 못 줄였다 (주식 -25.7% vs 모델 -23.5~-24.9%).
- 4개 조합 모두 검증 미달 -> 문서 규칙에 따라 모델 5는 최종 테스트를 열지 않고 종료.

## 결론
- 모델 5: 종료. 모델 1: 의미 있는 우위 없음 (형식상 충족 조합은 노이즈 수준).
- 문서의 "두 모델 모두 실패" 항목에 따라 **정액적립 유지**, 백테스트 엔진은 다음 아이디어에 재활용.
- 최종 테스트는 "최종 테스트 실행해줘" 지시 전까지 실행하지 않음.

## 해석을 보탠 부분 (문서에 없던 것)
- 모델 1: 하락 점수 변동성 = 직전 252일(연율). 1-D 기본 비중 40/40/10/10.
- 모델 5: 하락 강화 = SPY·QQQ 혼합 지수 -20% 진입, 고점 회복 시 복귀, 전환일에 채권 매도·주식 매수. 5-D는 100:0.
- 샤프 무위험 금리 0.

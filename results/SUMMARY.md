# 미국 ETF 분할매수(하락 매수) 백테스트 — 지금까지 정리 (최종 테스트 미실행)

## 진행 상태
- 1단계 데이터 수집 완료 / 2단계 백테스트 구현 / 3단계 비용 민감도·사전 점검·정합성 검사 완료
- 최종 테스트(2023~): **봉인 유지**. `python3 src/final_test.py --confirm-final-test` 는 사용자가 "최종 테스트 실행해줘"라고 할 때만 실행.
- 설정 변경 **4/5** 사용 (남은 1회 미사용). 계획서(PLAN_분할매수.md)는 중간에 수령, 대조 후 구현 정정.

## 확정 설정
회당 1,000 고정 / 주요(SPY,QQQ) -5% / 비주요(XLE,XLF) -15% / -5,-10,-15…% 단계별 1회 / XLF는 전일 금리차(DGS10-DGS2) >= 0일 때만 /
월 1,000 입금(자산당) / 다음날 시가 체결 / 편도 0.075% / 대기 현금에 전일 DGS2 이자

## 설정 변경 이력
| 번호 | 내용 | 결과 |
|---|---|---|
| (정정) | 대기현금 비율 매수 -> 회당 고정 금액(계획서) | 구현 오류 정정, 변경 1(50->100%) 폐기, 횟수는 보수적으로 1/5 유지 |
| 2/5 | 주요 -5% -> -3% | 미채택: 수익률 격차는 줄었으나 평균 단가 우위 상실 |
| 3/5 | 회당 1,000 -> 2,000 | 미채택: 학습에서 SPY/QQQ 단가 우위 소폭 축소 (근소 미달) |
| 4/5 | 하락 단계 비례 매수 | 미채택: 학습 QQQ 단가 우위 축소 (근소 미달), 검증 이익은 2020-03 한 사건에 집중 |

## 핵심 결과 (학습 / 검증, 합산)
- B 기준(입금 동일, 현금 포함): 하락매수 +17.4% / +6.5% vs 정액 +53.9% / +31.9%. 현금 대기 비율 77~79%. 최대낙폭은 -5.7%·-7.4% vs -23.0%·-39.2%.
- A 기준(동일 자본, 사용자 선택, 결과를 본 뒤 정한 평가 정의): 하락매수 +91.1% / +18.8% vs 정액 +75.6% / +14.0%. 항등 시험 통과, 무작위 날짜 대조에서 8건 중 7건 유리(77~97 백분위), QQQ 검증 44 백분위(우위 없음).
- 합격 기준(사전 점검): 1 평균단가 — 학습 4종 O, 검증 QQQ X / 2 총수익률 — B 미달, A 충족 / 3 XLF 금리 조건 — 한 번도 작동 안 해 검증 불가 / 4 매수 횟수 61·39회 O.
- 비용(0.05~0.1%)은 결과에 거의 영향 없음.

## 알려진 한계와 주의
- 수익률 구조: 현금 드래그 때문에 B 기준에서는 정액적립을 못 따라감. 학습 48개 조합 탐색에서도 최고 +48.9% < +53.9%. 수익률을 올릴수록 평균 단가 우위·낙폭 방어가 줄고 정액적립에 가까워짐.
- XLF 금리 조건: 8번의 -15% 신호가 모두 금리차 양수일 때 발생. 2022-07~12 역전 구간에는 단계 방식(전고점 갱신 전까지 단계당 1회) 때문에 신호 자체가 불가. '단계' 해석은 계획서에 없는 제 해석이며, 바꾸면 규칙 변경.
- 표본이 작음(XLE 검증 2회, XLF 3회). A 평가는 사후 정의라 우위의 증거로 쓰기 어려움.
- 누수 점검: 신호 prefix 불변, 다음날 시가 체결, 항등 시험 통과 — 누수 징후 없음.

## 열린 결정 사항 (사용자)
1. 최종 테스트 전에 마지막 변경 1회를 쓸지 (후보: 회당 2,000 — 이미 변경 3에서 검증 구간을 본 값, 기준 사전 합의 필요). 현재 권장: 조정 없이 진행.
2. XLF 금리 조건의 '단계' 해석을 바꿔 효과를 검증 가능하게 만들지 (변경 5/5 소모).
3. 최종 테스트 미달 시 '새 시도'(하락률 기준 또는 비주요 종목만 변경, 최대 2회)를 어느 구간에서 판정할지 (계획서에 명시 없음).

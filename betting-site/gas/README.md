# 도박장 — 구글 앱스 스크립트 버전

서버·호스팅 없이 **웹 앱 링크 하나**로 돌아가는 버전입니다. 데이터(유저·도박·채팅·상점)는 이 스크립트가 붙은 **구글 시트**에 저장됩니다.
(Node 서버 버전은 `../server.js`, 규칙은 동일합니다.)

## 설치 (약 5분)

1. [sheets.new](https://sheets.new)로 새 구글 시트를 만든다. 이름은 아무거나 (예: `도박장 데이터`).
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본으로 있는 `Code.gs`의 내용을 지우고, 이 폴더의 **`Code.gs`** 내용을 붙여넣는다.
4. 왼쪽 파일 목록 **`+` → HTML** 로 파일을 두 개 만든다. 이름은 정확히 `index`, `admin` (확장자는 자동).
   각각 이 폴더의 **`index.html`**, **`admin.html`** 내용을 붙여넣는다.
5. 위쪽 함수 선택칸에서 **`showAdminLink`** 를 고르고 ▶ 실행 → 권한 요청이 뜨면 허용.
   (처음엔 "확인되지 않은 앱" 경고가 뜨는데, 본인이 만든 스크립트라 **고급 → 이동** 으로 진행하면 됩니다.)
6. **배포 → 새 배포** → 유형 ⚙ **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나온 `https://script.google.com/macros/s/.../exec` 가 **친구들에게 보낼 링크**입니다.
7. 배포 후 `showAdminLink`를 한 번 더 실행하면, 시트의 **`관리자` 탭**에 **관리자 링크**가 적힙니다. 나만 알고 있으세요.

## 알아둘 점

- **코드를 고친 뒤**에는 *배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포* 를 해야 링크에 반영됩니다.
- 구글 로그인은 쓰지 않고 **닉네임 + PIN 4자리**로 로그인합니다 (앱스 스크립트는 방문자의 구글 이메일을 안정적으로 주지 않아서).
- 호출마다 구글 서버를 거쳐 **반응이 약 1초** 걸리고, 채팅은 약 4초마다 새로고침됩니다.
- 시트의 `users`, `wagers` 등 탭은 **직접 고치지 마세요** (고치면 데이터가 꼬일 수 있어요). 점수 조정은 관리자 페이지에서 하세요.
- 시트를 다른 사람에게 공유하지 마세요. PIN은 해시로 저장되지만, 시트 자체는 주인만 보는 게 안전합니다.
- 화면(`../public/*.html`)을 고쳤다면 `node ../build-gas.js` 로 이 폴더의 `index.html`, `admin.html`을 다시 만들 수 있습니다.
- 규칙(역배 보너스, 럭키 확률, 상점 가격)은 `Code.gs` 맨 위 `CFG`와 `SHOP`에서 바꿉니다.

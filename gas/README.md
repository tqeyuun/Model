# 시장 날씨판 — 구글 앱스 스크립트 설치 (5분)

페이지를 열 때마다 FRED 최신 자료로 계산합니다 (6시간 캐시). 컴퓨터를 켜 둘 필요 없습니다.

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 전체를 붙여넣기
3. 왼쪽 **파일 +** → **HTML** → 이름 `Index` → 이 폴더의 `Index.html` 전체를 붙여넣기
4. 저장 → 오른쪽 위 **배포** → **새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **나만** (가족과 보려면 '모든 사용자')
5. **배포** → 권한 승인 (외부 URL 접근, 처음 한 번) → 나온 **웹 앱 URL**을 휴대폰 홈 화면에 추가

## 선택: 매달 1일 요약 메일
편집기 위쪽 함수 목록에서 `installMonthlyTrigger` 선택 → **실행** (한 번만). 매달 1일 오전 8시에 종합 국면과 지표 요약이 내 메일로 옵니다.
끄려면 왼쪽 **트리거(시계 아이콘)** 에서 삭제.

## 코드를 고친 뒤
배포 → 배포 관리 → 연필 → 버전 **새 버전** → 배포 (URL은 그대로).
